Sobre o projeto

Uma plataforma pensada para reduzir dúvidas antes do intercâmbio.

O projeto centraliza informações que normalmente ficam espalhadas: pacotes, destinos, agências, avaliações, fórum de dúvidas e suporte ao usuário em uma experiência mobile-first.

Segurança e tecnologia

Construído com foco em autenticação, API e proteção de dados.

O projeto evoluiu de uma base local para uma arquitetura com API online, autenticação JWT, validações de entrada e controle de sessão por tipo de conta.

Autenticação via API

Fluxo com login, cadastro e token JWT emitido pelo backend, evitando sessões locais soltas e inconsistentes.

Separação de perfis

Intercambistas e agências possuem fluxos, telas e permissões diferentes para reduzir erros de acesso.

Validação e sanitização

Entradas do usuário passam por validações e tratamento contra conteúdo suspeito antes de serem exibidas ou salvas.

Imagens e uploads

Pacotes e agências usam imagens enviadas por API, com URLs normalizadas para exibição segura no aplicativo.

Sobre nós

Somos uma equipe criando uma ponte entre intercambistas e agências.

Nosso objetivo é transformar a busca por intercâmbio em uma experiência mais organizada, segura e transparente. O projeto combina desenvolvimento mobile, backend, design de interface, chatbot e boas práticas de segurança.

O Mapa do Intercambista nasceu como uma solução acadêmica com mentalidade de produto real: evoluímos o MVP com API online, perfis separados, dashboard para agências, imagens, avaliações e uma experiência visual inspirada em apps modernos.
